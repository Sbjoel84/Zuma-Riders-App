# Design preview

Clickable mock-ups of the main screens, made on a Claude design canvas. They use sample data and are not connected to the API.

| File | Screen |
|---|---|
| `preview/Main.dc.html` | Passenger: set route and offer a fare |
| `preview/Offers.dc.html` | Passenger: compare driver offers |
| `preview/Trip.dc.html` | Passenger: driver on the way, trip PIN |
| `preview/Driver.dc.html` | Driver: incoming request and counter-offer |
| `preview/Admin.dc.html` | Admin operations console: overview, live map, rides, drivers, verification, passengers, finance, pricing, support, safety, settings |
| `preview/canvas.json` | Layout of the screens on the canvas |

These files are the source of the design canvas and need its runtime to render; they are kept here as the reference for building the real admin dashboard and for keeping the mobile apps consistent with the agreed look.
